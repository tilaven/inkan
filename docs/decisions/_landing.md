## How to read these docs
Start with the [quick start](quick-start.md), then keep the [configuration reference](configuration.md) open.

Every feature of Inkan is described by an **ADR** in one of the projects below: why it exists, what was decided and how to use it.
Ideas that are not built yet are **RFCs** and wait on the backlog. The site is built with Inkan from the `docs/` folder of the repository,
so what you are reading is also what your own records will look like.
